# Review — post, analysis, scale (2026-10-01/02)

Scope: `crates/graph-core/src/post/**`, `crates/graph-core/src/analysis/**`,
`crates/graph-core/src/scale/**`, and their rows in `crates/graph-cli/src/capabilities/`.
Read-only review; no code change. Layouts are covered by the `scigraphs-conformance`
job and a separate 2026-10-01 layout review.

Method: one `explore` subagent per module (10 slices), merged, deduplicated and
verified here. Every BLOCKER/MAJOR below carries either a command with its real output
(a scratch test run under `scripts/orch/gr`, not committed) or the reference `file:line`
the code disagrees with. Findings that could not be proved are under **Unverified**,
never in the table. Severity: BLOCKER = wrong results / panic / NaN on a legal input;
MAJOR = wrong or degenerate result not caught, a D1–D10 risk, or complexity worse than
the row declares; MINOR = minor robustness or a duplicated primitive.
