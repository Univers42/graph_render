# Review — harness and the TypeScript SDK

Reviewed at `origin/develop` `1cca30e` ("updated"). Scope: `harness/**` other than
`scigraphs-conformance*` (47 files) and `crates/graph-sdk-js/**` (21 files). No code was changed;
`docs/reviews/review-harness-sdk.md` is the only path written.

Rules of record: `prompts/jobs/review-core-post.md` (the shape), `CLAUDE.md` "House limits",
`prompt.md` §6 D1–D10. Specs: `docs/contract/wasm-abi.md` for the SDK,
`docs/contract/ingest-schema.json` + `fixtures/ingest/expected-graph.json` for the adapters,
`docs/contract/snapshot-schema.json` for the raw-snapshot arm.

**Scope reading, recorded.** The body writes "Scope: `harness/**` other than `scigraphs-conformance*`
(the oracle arms: `oracle-*.mjs`, `oracle-*.py`, `wasm-run.mjs`, `sdk-smoke*`, `stress-d3.mjs`)" and
then asks "does each arm call the library it names with the parameters the fixture states" — a check
that is about exactly those arms. The two readings disagree, so the review covers **all 47** files,
which is the superset of either. Nothing outside the two excluded patterns was reviewed.

**Method.** Twelve `explore` subagents, one per module, in one fan-out; every BLOCKER/MAJOR row below
was then re-derived by hand. 4 of the 4 BLOCKERs and 26 of the 38 MAJORs carry a command or its
output; the rest cite a `file:line` in the tree or in a pinned reference. Claims a subagent raised
that I could not reproduce are in *Unverified* rather than in the table.
