# Review: `layout/force/**`, `forceatlas2*`, `spectral*`, `pivot_mds*`, their registry rows

Reviewed `origin/develop` @ `74f8994` (job start). Read-only: no code changed. Sixteen `explore`
subagents, one per module; every row below was then re-verified by me against the source, and every
BLOCKER/MAJOR either carries a command I ran in this job or a `file:line` in the reference it
disagrees with.

**Scope note.** `igraph`-derived layouts (`davidson_harel`, `drl`, `graphopt`, `lgl`,
`kamada_kawai`, `fruchterman_reingold`) are checked against `docs/layouts/layout.force.*.md` — the
repo's own transcription of the spec — and igraph's documented behaviour. No igraph C source was
opened.

**Disproven during verification (recorded so they are not re-raised).** Seven candidate findings
failed to reproduce and are *not* rows: `cover()` at `quadtree.rs:128` does converge for
`|coord| = 1e17` and `1e18` and `1e300` (it doubles `z`, so it terminates in O(log coord) — measured
1, 2 and ~1000 iterations); `drl.rs:161` `damping = 1 - damping_mult` is the spec verbatim
(`docs/layouts/layout.force.drl.md:42`); `drl.rs:208` comparing `sqrt(deg)·d²` against `cut_length`
is the spec verbatim (`layout.force.drl.md:43`); `drl/schedule.rs:90` `phases[stage+1]` is
unreachable because `sweeps` (`drl.rs:131`) exits on `finished()`; `start_temp: NaN` returns
`Err(NonFinite)` rather than being accepted; `start_temp: 1e37` yields `5.67e33`, inside `f32`, so
no overflow; and every `scale_ceiling` *is* enforced, by `graph-cli bench`
(`crates/graph-cli/src/bench.rs:202-210`).

## Unverified

Listed here rather than as findings, because the evidence was not obtained in this job.

- **`forceatlas2/state.rs:217`** (LF-08) — the reference form of the adaptive-speed jitter could not be

  container. Per `AGENTS.md` that is a STOP, so the mismatch is argued from the code's own internal
  cap (`jt`) rather than from the oracle. Do not act on it until the pinned reference is available.

  `f32::MAX`. `start_temp: 1e37` on `fruchterman_reingold` produced `5.67e33`, comfortably inside
  range. The pattern is real by inspection; the reachability is unproven.

  `delta/k`, and whether the reference's `opening` is a scalar max or a per-axis vector (which would
  make `D = 3` diverge from any `D = 2` run with unequal x/y spans), both need
  `d3-force`'s `layout.js:705-719`, which is not on disk in this container.
- **`barnes_hut/charge.rs:261` and `link.rs:84`** — whether a zero-distance pair can still divide by
  zero turns on whether `crate::rng::jiggle` can return exactly 0.0. That function was outside the
  read budget.
- **`pivot_mds.rs:93`** — the justification for dropping the reference's `covered[chosen] = -1.0`

  safe there (`covered[i] == 0` iff `i` is a chosen pivot) and `pivot_mds/tests.rs:158-184` pins it
  against a `-1`-marking oracle. A wrong comment, not a defect; recorded so it is not re-raised.
- **`live_params.rs:238`** — `validate_finite` checks finiteness only, so the frozen path admits

  determined; the setters were outside the read budget.

  validation order. Whether every force term honours a pin, and whether a paused run is
  bit-identical to a batch run, live in `sim.rs`/`gravity.rs`, outside this review's file budget.
  Not a pass.
- **`force/params.rs:83` (`TICKS = 112`)** — hand-pinned and justified only by a doc comment. No
  rule is broken; recorded because a silent rot path exists if `alpha_decay` ever changes.

## Method and limits

- Sixteen `explore` subagents, one per module, dispatched in a single message; results merged,
  deduplicated and then individually re-verified by me. Seven candidate findings did not reproduce
  and were dropped (listed at the top).
- Verification commands ran through `scripts/orch/gr` inside the `ge-rust` image, on the compiled
  test binary directly where a hang had to be bounded by `ulimit`/`timeout`. The scratch harness
  used for them was removed before this report was written; `layout::force` is green at 181 passed,
  0 failed.
- igraph's C sources were never opened.
- The pinned reference tree is **absent** in this container, so no oracle diff was run. Every
  reference citation above is to `docs/layouts/*.md` (in-repo) or to a `file:line` quoted by the
  code under review. Findings that need the pinned tree are in the unverified list.
